# Contributing guidelines

Use GitHub Issues and the M0–M5 roadmap. Branch from protected `main` using `feat/123-summary`, `fix/123-summary`, etc. Conventional Commits and squash merges. PRs must link issue, state version matrix, tests, migration/security impacts, docs, rollback and compatibility impacts. High-risk migrations, privileges and core patch changes need designated codeowner review. See [coding standards](docs/09-engineering-standards.md) and [agent instructions](AGENTS.md).
