# 17 — Naming options (10)

**Criteria:** pronounceable, easy to associate with WordPress + PostgreSQL, developer-friendly CLI, minimal ambiguity. **These are creative options only; domain, GitHub organization, package-registry and trademark availability have NOT been checked.** WordPress naming/branding guidelines must be respected.

| # | Proposed name | Rationale | Caveat |
|---|---|---|---|
| 1 | **Pressgres** | Press + Postgres, shortest immediate connection | may already be used; clearance needed |
| 2 | **WPgres** | WordPress abbreviation + PG | abbreviated WordPress brand usage |
| 3 | **PostgresPress** | Both platform names explicit | longer, similar naming likely exists |
| 4 | **PgPress** | compact technical name | PG alone may be less clear to novices |
| 5 | **PressPG** | simple install-package name | could sound like a generic integration |
| 6 | **WPGateway** | WordPress database gateway implication | PostgreSQL less explicit |
| 7 | **WPPostgres** | most searchable and descriptive | generic, trademark/domain concerns |
| 8 | **PressgreSQL** | playful Press + PostgreSQL | harder spelling/pronunciation |
| 9 | **PgBridgeWP** | communicates adapter/bridge role | technically descriptive, less memorable |
| 10 | **PostgrePress** | Postgres + Press, memorable | similar to existing terms possible |

**Recommendation:** **Pressgres** as working project name; **`wps`** as CLI (short for WordPress Shell), `pressgres` as package/repo name, e.g. `pressgres/pressgres`. Validate clearance before any public logo, DNS/domain or product launch. No name is guaranteed unique.
